
# Отчет об анализе уязвимостей Docker образов



**` Multi-Projects | Trivy dev, Grype 0.99.1 | 2025-09-07`**

## Обзор исследования

Данный отчет представляет результаты комплексного security-аудита Docker-образов уязвимых веб-приложений. Анализ проводился с использованием современных инструментов SAST (`trivy`, `grype`) для выявления 0-day и известных уязвимостей в зависимостях контейнеров.

## Контекст исследования

**Цель:** Выявление критических уязвимостей в учебных приложениях и разработка практических рекомендаций по их устранению.

Методология:

- Статический анализ зависимостей (SCA)

- Сканирование на наличие CVE в базовых образах

- Оценка уровня риска по CVSS v3.1

- Приоритизация по критичности воздействия

Проанализированные репозитории:

- [`OWASP Juice Shop`](https://github.com/juice-shop/juice-shop.git
) — современное Node.js приложение
- [`VulnApp by Meera Subbarao`](https://github.com/meerasubbarao/vulnapp.git
) — приложение с уязвимостями
- [`VulnApp by Bhagavan Bollina`](https://github.com/Bhagavan-Bollina/vulnapp.git
) — мультиязычное учебное приложение
- [`VulnApp demo-poc`](https://github.com/demo-poc/vulnapp.git
) — демонстрационный контейнер
- [`bWAPP`](https://github.com/lmoroz/bWAPP.git
) — классическое приложение на PHP


## Топ-10 критических уязвимостей

### 1. Уязвимость в PHP (CVE-2025-1861)

| **Параметр** | **Значение** |
|--------------|--------------|
| **Уровень риска** | `[CRIT]` Критический (CVSS: 9.8) |
| **Затронутые образы** | bWAPP, VulnApp-meera |
| **Уязвимые пакеты** | php-cli 7.4.33, libphp 7.4.33 |
| **Исправлено в версии** | PHP ≥ 8.1.32 |

**Описание:** 
Уязвимость в обработке HTTP редиректов в PHP позволяет злоумышленнику осуществлять переадресацию на произвольные URL из-за ограничения буфера в 1024 байта вместо рекомендуемых RFC 9110 8000 байт.

**Воздействие:**
- Подмена URL при редиректах
- Фишинг атаки
- Перенаправление на malicious domains

**Рекомендации:**
```dockerfile
# Обновить базовый образ до актуальной версии PHP
FROM php:8.1-apache
```

### 2. Уязвимость в SQLite (CVE-2025-6965)

| **Параметр** | **Значение** |
|--------------|--------------|
| **Уровень риска** | `[CRIT]` Критический (CVSS: 9.8) |
| **Затронутые образы** | bWAPP, VulnApp-meera |
| **Уязвимые пакеты** | libsqlite3-0 3.34.1-3 |
| **Исправлено в версии** | SQLite ≥ 3.50.2 |

**Описание:** 
Integer overflow в SQLite позволяет превысить количество агрегатных терминов над доступными колонками, приводя к повреждению памяти.

**Воздействие:**
- Коррупция памяти
- Возможное выполнение произвольного кода
- Отказ в обслуживании

**Рекомендации:**
```dockerfile
# Обновить пакет SQLite в Debian
RUN apt-get update && apt-get install -y libsqlite3-0=3.50.2-1
```

### 5. Уязвимость в vm2 (CVE-2023-37903, CVE-2023-37466)

| **Параметр** | **Значение** |
|--------------|--------------|
| **Уровень риска** | `[CRIT]` Критический (CVSS: 10.0) |
| **Затронутые образы** | Juice Shop |
| **Уязвимые пакеты** | vm2 3.9.17 |
| **Исправлено в версии** | Не поддерживается (использовать альтернативы) |

**Описание:** 
Множественные уязвимости escape из sandbox в библиотеке vm2, позволяющие выполнить произвольный код на хосте.

**Воздействие:**
- Полный escape из sandbox
- Выполнение произвольного кода на хосте
- Компрометация всей системы

**Рекомендации:**
```dockerfile
# Удалить уязвимый пакет vm2
RUN npm uninstall vm2
# Использовать альтернативы: isolated-vm, worker threads
```
